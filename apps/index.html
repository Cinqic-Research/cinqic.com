01 — Featured app

Juniper

Local-first AI software for people who want a thoughtful assistant, visible model controls, and a clear boundary around private data.

Flagship · published prerelease 0.3.0-rc.33

Yours to configure.

Juniper gives you a chat-first workspace, assistant profiles, device-aware model recommendations, verified resumable model downloads, provider choices, explicit tool permissions, local persistence, visible data-route boundaries, and appearance settings for theme, contrast, accent, font, and layout.

0.3.0-rc.33 is the current source version and the latest published prerelease. It is a release candidate, not a promoted 0.3.0 release.

Published platforms
Windows x64, Linux x86_64, Android 7.0+
Desktop runtime
Juniper-owned loopback llama.cpp process
Android note
